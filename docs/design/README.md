# Дизайн GUI (Этап 2)

Источник: холст «stlink-rust-ui — GUI» в Claude (Design). Здесь лежит копия его исходников:

- `Main.dc.html` — **все экраны, оверлеи, тексты на двух языках и логика переходов в одном файле** (интерактивный прототип). Главный источник для вёрстки: разметка, CSS-токены, словарь `T` (ru/en), данные журнала `LOG`.
- `canvas.json` — раскладка холста и заметки (правила быстрой записи — `notes.sQuick`, освобождение программатора — `notes.sConn`, настройки/журнал — `notes.sSet`). Остальные артборды холста — тонкие обёртки, которые показывают `Main` в конкретном состоянии (`screen`, `overlay`, `lang`, `dark`, `auto`), поэтому сюда не скопированы.

Формат `.dc.html` — не React: `{{hole}}` = значения из `renderVals()`, `<sc-if>`/`<sc-for>` = условия/циклы. Переносить в React + TS вручную, сохраняя структуру, токены и тексты.

## Общее

- Стиль: нативный macOS. Шрифт `-apple-system` (SF Pro), моноширинный `ui-monospace` (SF Mono) для адресов, hex, версий, CRC, журнала.
- Тема: Системная / Светлая / Тёмная (настройка). Токены — CSS-переменные в `.win` / `.win.dark`.
- Язык: Системный / Русский / English (настройка). Все строки — в словаре `T` в `Main.dc.html`; в приложении вынести в `src/i18n/{ru,en}.ts` с теми же ключами. Числа: в ru десятичная запятая (`3,28 В`), в en точка (`3.28 V`).
- Окно: 920×620 (минимальный размер), titlebar 52 px с traffic lights, степпером и кнопками «Журнал» и «Настройки»; footer 60 px с действиями.
- Мастер из 3 шагов: **Устройство → Параметры → Выполнение**.

## Экраны (`screen`)

| screen | Что |
|---|---|
| `empty` | Нет устройства, ожидание (hot-plug). Если включена автозапись — плашка «запишется сразу после подключения этого же STM32H743» + «Выключить» |
| `released` | Программатор найден, но **не занят приложением** (после «Освободить» или при выключенном автоподключении). Кнопка «Подключиться», данные из USB-дескриптора (модель, VID:PID, серийник). Автозапись на паузе |
| `device` | Карточка «Быстрая запись»; карточки «Программатор» и «Микроконтроллер»; три действия: «Записать прошивку», «Прочитать в файл», «Стереть всё» (красная). Footer: статус «подключён» + «Освободить», справа «Перезагрузить МК» (аппаратный сброс и запуск) |
| `eraseConfirm` | Sheet поверх `device`: стереть весь flash (оба банка, адреса), красная кнопка «Стереть всё» |
| `eraseProgress` / `eraseDone` | Стадии «Банк 1», «Банк 2» (красный прогресс); итог: «Flash стёрт», МК остановлен; «Записать прошивку» |
| `write` | Файл .bin, адрес, галочки «Проверять», «Перезагружать МК», «Перезаписывать при изменении файла»; карта flash, оценка времени. «Стереть и записать» |
| `confirm` | Sheet поверх `write`: какие сектора и адреса будут стёрты (из `flash::plan_write`) |
| `writeProgress` / `writeDone` | 3 стадии: стирание, программирование, проверка; итог с CRC32, «Записать снова ⌘R» |
| `read` / `readProgress` / `readDone` | Область (весь flash / банк 1 / банк 2 / диапазон), имя файла, прогресс, итог с CRC32 и «Показать в Finder» |

## Оверлеи (`overlay`, sheet поверх любого экрана)

- **Настройки** (кнопка в titlebar, ⌘,). Две колонки:
  - Общие: Язык, Оформление.
  - Запись: Проверять после записи, Перезагружать МК после записи, Всегда спрашивать перед стиранием.
  - Программатор: Подключаться автоматически, Частота SWD (4 МГц / 1,8 МГц / 950 кГц / 480 кГц), Подключаться со сбросом, Держать отладку в low-power.
  - Журнал: Подробный журнал USB (TRACE).
  Настройки сохраняются (Tauri store); «Проверять» и «Перезагружать» — те же флаги, что галочки на экране записи.
- **Журнал** (кнопка в titlebar). Фильтр Все / Ошибки (WARN+ERROR) / USB (TRACE); «Копировать», «Сохранить…», «Очистить»; строки: время, уровень (бейдж), сообщение моноширинным; ERROR подсвечены. TRACE-пакеты появляются, только если включён «Подробный журнал USB». Источник — `tracing` из `stlink` (уровни как в библиотеке).

## Освобождение программатора

- «Освободить» закрывает устройство (drop `StLink` → выход из debug), чтобы ST-Link могли взять VS Code, OpenOCD или st-flash. Переход на `released`.
- Пока программатор освобождён, приложение его не открывает, даже при включённом «Подключаться автоматически», и автозапись на паузе; «Подключиться» снова открывает его.
- Если устройство занято другой программой (`Error::Busy`) — показывать `released`-подобное состояние с текстом «занят другой программой» и кнопкой «Повторить» (`TODO(design)`).

## Быстрая запись — правила

- Последний файл и адрес запоминаются для каждого чипа (по UID).
- «Записать ⌘R» запускает запись сразу, без мастера. Подтверждение пропускается, только если стираются те же сектора, что при последней подтверждённой записи, и выключено «Всегда спрашивать перед стиранием»; иначе — обычный `confirm`.
- «При подключении платы»: запись стартует при подключении только того же чипа (UID); выключается при выборе другого файла.
- «При изменении файла»: слежение за .bin; запись через ~1 с после последнего изменения (debounce), не запускается, если CRC не изменился или идёт другая операция.

## Значения в макетах

Серийник, UID, CRC, имена файлов, время и строки журнала — примеры. Реальные значения брать из `stlink` (`ProbeInfo`, `TargetInfo`, `Progress`, tracing).

## Реализация

Фронтенд (`src/`) повторяет прототип на React 19 + TypeScript без UI-китов: токены и общие классы из `Main.dc.html` лежат в `src/styles/tokens.css` без изменений, разметка экранов перенесена с теми же размерами и текстами. Rust пока не подключён: всё работает на `MockBackend`.

| Где | Что |
|---|---|
| `src/backend/types.ts` | DTO будущих Tauri-команд, зеркалят типы `stlink` (`ProbeInfo`, `TargetInfo`, `FlashPlan`, `Progress`, `BackendError { kind, message }`) |
| `src/backend/Backend.ts` | Интерфейс бэкенда: hot-plug, `identify`, `planWrite`, `write`/`read` с прогрессом и `AbortSignal`, `resetAndRun`, выбор и слежение за файлами, настройки быстрой записи по UID |
| `src/backend/mock/` | `MockBackend`: стенд (ST-Link V2J46S7 + STM32H743, 3,28 В) на таймерах, скорости из CLAUDE.md, настройки в `localStorage` |
| `src/backend/index.ts` | Выбор реализации. Сейчас всегда mock (`TauriBackend` — TODO) |
| `src/domain/` | Чистая логика с тестами: порт `plan_write` из `geometry.rs`, валидация адресов, оценки времени, форматирование, правила быстрой записи |
| `src/state/machine.ts` | Машина состояний (`reducer`): экраны `empty … readDone`, формы, операция, плашки ошибок |
| `src/state/controller.ts` | Побочные эффекты: вызовы бэкенда, отмена, debounce слежения за файлом, сохранение настроек |
| `src/components/`, `src/screens/` | Общие компоненты (`WindowChrome`, `FlashMap`, `ConfirmSheet`, …) и экраны |
| `src/dev/DevPanel.tsx` | Dev-панель mock-режима |

**Запуск:** `npm run dev` (браузер, http://localhost:1420) или `npm run tauri dev`. Проверки: `npm run build` (tsc + vite), `npm test` (vitest: `domain/` и reducer).

**Dev-панель** есть только в mock-режиме: **⌥⌘D** (Alt+Ctrl+D вне macOS) открывает и закрывает её. С панели можно подключить или отключить программатор, сымитировать пересборку отслеживаемого файла (с новым CRC или с тем же), задать ошибку для следующей операции (`Disconnected` посреди записи или чтения, `CoreNotAccessible`, `FlashProtected`, `Busy`) и множитель скорости ×1/×5/×20. Сбросить сохранённые настройки быстрой записи: удалить ключи `stlink-ui.quick.*` в `localStorage`.

**Клавиатура:** ⌘R (Ctrl+R) — быстрая запись на экранах «Устройство» и «Готово»; в sheet подтверждения Enter подтверждает, Esc отменяет, Tab не выходит за пределы sheet.

**Окно Tauri:** 920×620 (это же минимальный размер), `titleBarStyle: Overlay` + `hiddenTitle`. Системные traffic lights выводятся поверх нашего titlebar, нарисованные кружки показываются только в браузере. В titlebar стоит `data-tauri-drag-region`, двойной клик разворачивает окно (разрешения в `capabilities/default.json`).

**Ограничения mock-режима:** в браузере нет диалога сохранения: «Изменить…» спрашивает имя файла, результат чтения скачивается. В Tauri-webview скачивание не работает (файл не сохраняется), и drag-and-drop перехватывает сам Tauri. Это закроет `TauriBackend`.

**Не нарисовано в макете** (помечено `TODO(design)` в коде): плашки ошибок, карточка МК во время и после неудачного подключения, карточка быстрой записи без файла, МК без драйвера flash.
