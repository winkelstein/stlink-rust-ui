# Flash layouts the stlink .chip files do not describe: non-uniform sectors,
# several banks, and bank modes chosen by option bytes.
#
# Layout rows:
#   chip_id  mode  bank1_runs [| bank2_runs]
#   runs: <count>x<KiB>, e.g. `4x16 1x64 7x128` = 4 × 16 KiB, 1 × 64 KiB, 7 × 128 KiB
#   mode: single  one bank, cut to the flash size
#         dual    two equal banks, each cut to half the flash size
#         fill    banks filled in order up to the flash size (F1 XL)
#   A row is a template for the largest part; smaller parts use its first
#   units (F401xC, 256 KiB: 4x16 1x64 1x128). If the chosen mode does not fit
#   the flash size, the other mode of the same chip is used (F42x 2 MiB parts
#   are always dual bank).
#
# Bank mode rows (option bytes are only read, never written):
#   bankmode  chip_id  register  bit  dual_when (set | clear)
#
# Chips with no row use uniform units of `flash_pagesize` in one bank (or two
# equal banks with the `dualbank` flag: H74x/H75x).
#
# Sources: RM0033 (F2), RM0090 (F405/F407/F42x/F43x), RM0368 (F401),
# RM0383 (F411), RM0390 (F446), RM0401 (F410), RM0402 (F412), RM0430 (F413),
# RM0386 (F469), RM0385 (F74x), RM0410 (F76x), RM0431 (F72x), RM0008 (F1 XL),
# RM0440 (G4).
