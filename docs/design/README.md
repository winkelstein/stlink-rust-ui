# Дизайн GUI (Этап 2)

Источник: холст «stlink-rust-ui — GUI» в Claude (Design). Здесь лежит копия его исходников:

- `Main.dc.html` — **все экраны и их логика в одном файле** (интерактивный прототип). Это главный источник для вёрстки: разметка, CSS-токены, тексты, состояния.
- Остальные `*.dc.html` — тонкие обёртки, которые показывают `Main` в конкретном состоянии (`screen=...`, `dark`, `auto`). Сами по себе ничего не содержат.
- `canvas.json` — раскладка холста и заметки (в т.ч. правила быстрой записи в `notes.sQuick`).

Формат `.dc.html` — не React: `{{hole}}` = значения из `renderVals()`, `<sc-if>`/`<sc-for>` = условия/циклы. Переносить в React + TS вручную, сохраняя структуру, токены и тексты.

## Общее

- Стиль: нативный macOS. Шрифт `-apple-system` (SF Pro), моноширинный `ui-monospace` (SF Mono) для адресов, hex, версий, CRC.
- Тема: светлая и тёмная по системе (`prefers-color-scheme`). Токены — CSS-переменные в `.win` / `.win.dark` в `Main.dc.html`, переносить как есть.
- Окно: 920×620 (минимальный размер), titlebar 52 px с traffic lights и степпером, footer 60 px с действиями.
- Мастер из 3 шагов: **Устройство → Параметры → Выполнение**. Степпер в заголовке окна. Справа в заголовке — кнопки «Журнал» и «Настройки» (их экраны ещё не нарисованы).

## Экраны (`screen` в Main)

| screen | Что |
|---|---|
| `empty` | Нет устройства, ожидание (hot-plug). Если включена автозапись — плашка «запишется сразу после подключения этого же STM32H743» + «Выключить» |
| `device` | Карточка «Быстрая запись» (последний файл, адрес, «Записать ⌘R», галочки «При подключении платы» / «При изменении файла»); карточки «Программатор» и «Микроконтроллер» (аналог `st-info --probe`); кнопки «Записать прошивку» / «Прочитать в файл»; «Сбросить МК» |
| `write` | Файл .bin, адрес, галочки «Проверить», «Сбросить и запустить», «Перезаписывать при изменении файла»; карта flash (стираемые сектора, область прошивки), оценка времени. Кнопка «Стереть и записать» |
| `confirm` | Sheet поверх `write`: какие сектора и адреса будут стёрты (из `flash::plan_write`) |
| `writeProgress` | Общий прогресс + 3 стадии: стирание, программирование, проверка. «Отменить», предупреждение «Не отключайте программатор» |
| `writeDone` | Итог: область, стёртые сектора, CRC32; «Записать снова ⌘R», «К устройству» |
| `read` | Область: весь flash / банк 1 / банк 2 / диапазон (адрес+размер), имя файла по умолчанию, оценка времени |
| `readProgress` / `readDone` | Прогресс чтения; итог с CRC32 и «Показать в Finder» |

## Быстрая запись — правила

- Последний файл и адрес запоминаются для каждого чипа (по UID).
- «Записать ⌘R» запускает запись сразу, без мастера. Подтверждение пропускается, только если стираются те же сектора, что при последней подтверждённой записи; иначе — обычный `confirm`.
- «При подключении платы»: запись стартует при подключении только того же чипа (UID); выключается при выборе другого файла.
- «При изменении файла»: слежение за .bin; запись через ~1 с после последнего изменения (debounce), не запускается, если CRC не изменился или идёт другая операция.

## Значения в макетах

Серийник, UID, CRC, имена файлов и время — примеры. Реальные значения брать из `stlink` (`ProbeInfo`, `TargetInfo`, `Progress`).
